# 🐳 Мой первый сайт-портфолио в Docker

Добро пожаловать в мой репозиторий! Это мой первый учебный проект, в котором я создал одностраничный сайт-визитку с плавной навигацией по разделам и упаковал его в изолированный Docker-контейнер.

## 🛠 Технологический стек:
* **Frontend:** HTML5, CSS3 (адаптивная верстка, плавная якорная навигация)
* **DevOps:** Docker, веб-сервер Nginx (Alpine-версия)

## 🚀 Как запустить проект локально:

Для запуска проекта на вашем компьютере должен быть установлен **Docker**.

1. Клонируйте репозиторий:
```bash
git clone https://github.com
```

2. Перейдите в папку проекта:
```bash
cd docker-portfolio
```

3. Соберите Docker-образ:
```bash
docker build -t portfolio-site .
```

4. Запустите контейнер:
```bash
docker run -d -p 8080:80 --name my-portfolio portfolio-site
```

После этого сайт будет доступен в вашем браузере по адресу: **http://localhost:8080**
